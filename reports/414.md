## Notes

1. **Soft temperature warning.** The row asked for "no throttle warning". Under the pi-test load, rpi-firmwared warned 4 times about the 60 °C soft limit (59.1–60.1 °C) and cleared it each time. The ARM clock stayed at 1400 MHz, and there was no under-voltage flag. This is the board's temperature in this room with no heatsink, not a software fault. Whether it blocks the release is for the release owner to decide.
2. **nc writes its `Remote host: …` line to stdout**, so `nc host:port > file` puts 35 extra bytes at the front of the file (known since rows 400/401). The data after that line is correct. Moving that line to stderr would make `nc > file` give a clean copy.
3. Sopwith was started from the shell, not from the desktop launcher, and DNS was checked with curl, because no person was there.
