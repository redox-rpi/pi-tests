A note from the test agent, unchecked: completion code 0x4 is the xHCI "USB Transaction Error". The device is **low speed behind the VL805's high-speed root hub**, on port 1.4. For that, the Address Device slot context needs the transaction-translator fields: the TT hub slot ID (1), the TT port number (4), and the hub's MTT and TT think time in the hub's slot context. If those are missing, a Transaction Error on Address Device is the usual result.
