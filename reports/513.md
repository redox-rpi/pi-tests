# 513: interrupt and timer counters in `/scheme/sys/irqstat` (#564, `irq-stats`), Pi 3B+

**Result: pass.**
- The file read three times with no error or hang, each in 0.3 s.
- `timer` grows on all four CPUs in each step. `line` 8 grows in step 3. The `wake_late` counts grow.
- `unexpected` stays 0, and pi-test passes 6/6.
- The highest `max_handler_us` is **23 µs**, far below 1000.

**Only one IRQ line shows up: line 8, always on CPU 0.** It is the cascade from the local interrupt controller to the GPU interrupt controller (`brcm,bcm2836-armctrl-ic`), so it carries UART, USB and network together.
- USB is dwc2: `dwc2d: interrupt /scheme/irq/phandle-1/1,9`, bank 1 IRQ 9 behind the cascade.
- The network goes through the LAN7800 on USB, so it is dwc2 as well.
- So the file cannot tell UART, USB and network apart. Per-device counts would need counting at the GPU controller (bank and bit) as well.
