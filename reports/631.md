## Step 6: what Mesa says

Without `LIBGL_ALWAYS_SOFTWARE` (the V3D path):

```
libEGL debug: EGL user error 0x3001 (EGL_NOT_INITIALIZED) in eglInitialize: DRI2: failed to load driver
libEGL debug: EGL user error 0x3001 (EGL_NOT_INITIALIZED) in eglInitialize: DRI2: failed to load driver
libEGL debug: Falling back to surfaceless swrast without DRM.
libEGL debug: MESA-LOADER: dlopen(/usr/lib/dri/swrast_dri.so)
libGL: Can't open configuration file /etc/drirc: No such file or directory.
libEGL debug: did not find extension DRI2_BufferDamage version 1   (also DRI2_Interop, DRI2_Blob, DRI_MutableRenderBufferDriver, DRI_Kopper)
gles-probe: EGL 1.4, Mesa Project
libEGL debug: Configurations: … 0x001 … 0x015 (pbuffer configs, es/es2/es3 renderable)
gles-probe: GL_RENDERER (null), GL_VERSION (null)
```

- So the **v3d DRI driver did not load** ("DRI2: failed to load driver", twice), and EGL fell back to surfaceless swrast. The log does not name the driver file it tried to open.
- With swrast, EGL initializes and lists configs, but `glGetString` returns NULL, so there is no current context. Then gles-probe crashes.
- With `LIBGL_ALWAYS_SOFTWARE=1`, the log is the same from "Falling back to surfaceless swrast" on, with the same crash.

## The crash

All four runs (PIDs 84, 93, 102, 111):

```
kernel::context::memory:DEBUG -- Lacks grant
FATAL: Not an SVC induced synchronous exception (ty=100100)
FAR_EL1: 0x0   ELR_EL1: 0000000001930264   ESR_EL1: 0000000092000007
UNHANDLED EXCEPTION, CPU #0, PID 84, NAME /usr/bin/gles-probe
```

This is a data abort reading address 0, at the same code address `0x1930264` each time. Most likely the probe or Mesa uses the NULL result of `glGetString` or a NULL context.

- The only `v3dd:` lines after the boot are one endless-job timeout and reset, which come from step 2's planned endless job: `timeout: bin job (1000 ms)`, state, `reset: done … (resets so far: 1)`, `job failed: timeout …`. So `gles-probe` never submitted a V3D job.
- Afterwards: config.txt restored, row 501's image at the login (22:39).
