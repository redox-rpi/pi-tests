## The crash

All six `prime-probe` processes (A: PIDs 67, 70, 156, 185; B: PIDs 65, 68):

```
FAR_EL1: 0x3dc00fe091148000   ELR_EL1: 3DC00FE091148000   ESR_EL1: 0000000082000004
UNHANDLED EXCEPTION, CPU #0, PID 67, NAME /usr/bin/prime-probe
```

- `ESR 0x82000004` is an instruction abort: the program jumped to `0x3dc00fe091148000`, which is not a code address at all. FAR equals ELR.
- It happens right after the extension check reports `no`. Most likely prime-probe calls an EGL or DMA-BUF function pointer that was never resolved, such as `eglCreateImageKHR` with an attribute list for an extension that is missing.
- The printed line is the same with and without `--show`, `--lifetime` and `--foreign`.
