## No HDMI sink on the 3B+

- Boot log ([1-boot.log](573/1-boot.log)):
  - `rpi-fbd: no EDID (no monitor, or the firmware does not read it)` and `656x416`. lab.md says this is the firmware's choice "when nothing is on HDMI".
  - `bcm2835-hdmiaudiod: … hotplug no, DVI mode, pixel clock 148.500 MHz (default)`, then `output was in DVI mode; HDMI mode did not come up`, and `no pixel clock from rpi-firmwared … nor PLLH`.
- In row 419 (2026-11-14) the firmware had set up HDMI (`pixel clock … (pllh)`, `HDMI mode`).
- The 3B+ boots in Test 570 this morning also show `656x416` (rc2 has no HDMI audio, so nobody looked). So the NanoKVM was probably not on the 3B+'s HDMI, or was off, already before this test. The cut-off first run shows the same.
