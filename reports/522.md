# 522: Pi 400 SD slot, the real EMMC2 clock (#307, PR #389, fcfe98e1), no card

**Result: pass, with one finding.**
- `bcm2835-sdhcid: EMMC2 clock up to 500 MHz` replaces `assuming 250 MHz`.
- The clocks file has an `emmc2` line, and the boot reaches `redox login:` with no panic.

**Finding: N = 500 MHz, but the base clock is 100 MHz.** The EMMC line reads `base clock 100 MHz), dividing 500 MHz`.
- The clocks file has `emmc2 100000000 500000000`. That is 100 MHz now and 500 MHz at most, and the controller's 100 MHz agrees with the current rate.
- So sdhcid takes the **maximum** rate, where it should take the current one.
- The divider would then come out 5 times too large, and the SD clock 5 times too slow. That is safe, but slow.
- With no card this cannot be seen in transfers.

- Pi 400, network boot from `/srv/tftp/pi400/`, no card in the slot, no person, no power cycle. Both boots came from `reboot` typed on the console. 2026-11-20, 09:20–09:25 UTC.

- U-Boot's network load failed twice and `boot` was typed twice, both for this image and for the restore. This is known (#394).
