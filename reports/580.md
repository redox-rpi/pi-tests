# Test 580 – rof v0.1.0-rc3 card on the Pi 3B+ (person test, user)

Date: 2026-11-22, about 18:15–19:15 UTC. The user swapped in the card `redox-rpi-rof-v0.1.0-rc3`, then watched HDMI and used the keyboard. The coordinator passed the result on, and the Pi test agent checked the 3B+ serial log ([580/serial.log](580/serial.log)).

Result: **pass** (as the user reports, and the serial log agrees).

- **The card boots to login with an HDMI picture** (user).
- The serial log has two card boots. Each one shows:
  - the banner `redox-rpi bootcode v0.1.0-rc3-d391b09 (release, boots from the SD card, boot screen on HDMI)`;
  - `dwc2d: link up on the LAN7800`, then `dwc2d: devices ready after 4335 ms` / `4337 ms`;
  - `bootscreen: Redox's last step, 5 steps`, then `redox login:`.
- `RELIBC PANIC` 0, `UNHANDLED EXCEPTION` 0.
- The user's note: the boot waits for the network. That is dwc2d waiting for the LAN link (about 3 s), which #614 removes (Test 578). #614 is not in rc3.

Afterwards the netboot selector card went back in. Stable `v0.6.0-dev-126-g1b6b4cd9+x2d42` was brought up with a plug power cycle, devsh up (19:22).
