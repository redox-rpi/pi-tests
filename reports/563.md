- No `RELIBC PANIC` or `UNHANDLED EXCEPTION` in either.

- So there was nothing to ping.
- The LAN does send router advertisements: the build host has global IPv6 addresses and two IPv6 default routes right now. In Test 210 the same procedure got global, ULA and route.
- `pi-test.py` standard checks: all pass (version, manifest, ps, ps-tty, sdcard, starts).
- Serial log: [563/a-serial.log](563/a-serial.log).

- **5 key logins: 0/5.**
