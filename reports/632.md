## Crash at the end of each gles-probe run

Three `UNHANDLED EXCEPTION`s, one per `gles-probe` process (PIDs 84, 93, 102 = steps 3, 4, 5), each after the run printed its PASS line:

```
kernel::context::memory:DEBUG -- Lacks grant
FATAL: Not an SVC induced synchronous exception (ty=100000)
FAR_EL1: 0x18f0480   ELR_EL1: 00000000018F0480   ESR_EL1: 0000000082000006
UNHANDLED EXCEPTION, CPU #2, PID 84, NAME /usr/bin/gles-probe
```

- `ESR 0x82000006` is an instruction abort: the program jumped to `0x18f0480`, where nothing is mapped, so FAR equals ELR. It happens at the same address with softpipe and with V3D, so it is probably at exit, in a destructor or `atexit` handler of an unloaded library.
- Test 631 crashed elsewhere: a NULL read at `0x1930264`, before any rendering.
